## 🔬 Featured Projects

### 🧬 Integrated Multi-Omics Analysis of DLBCL
**Dataset:** PRJNA605794 — 129 DLBCL patient samples (RNA-seq + WGBS)

**What I did:**
- Built complete RNA-seq pipeline: FastQC → fastp → HISAT2 → featureCounts → edgeR TMM normalization, QC'd down to 57 high-quality samples
- Performed WGCNA co-expression network analysis → 11 modules, identified hub genes (KDM5D/UTY, COL5A2, CD247, IGKV)
- Built a parallel WGBS pipeline using Bismark and methylKit for DNA methylation profiling
- GO/KEGG pathway enrichment analysis using gprofiler2
- Building a MOFA2 multi-omics integration pipeline linking DNA methylation to gene expression patterns (in progress)

**Tools used:** Python | R | Bash | Bismark | methylKit | MOFA2 | WGCNA | edgeR

🔗 [View Repository](https://github.com/arundhathiharishchandra-20/dlbcl-multiomics-analysis)

### 🧪 RXRα Fatty Acid Docking
In-silico investigation of fatty acid interactions with Retinoid X Receptor Alpha (RXRα) through homology modeling and molecular docking.

**What I did:**
- Structural modelling of human RXRα protein via PDB retrieval, cleaning, and zinc-retention using UCSF Chimera
- Built and validated 3D macromolecular models using Swiss-Model (LBD/DBD templates from InterPro)
- Performed molecular docking of fatty-acid ligands (ALA, DHA, EPA, AA) using PyRx, AutoDock Vina, and ADFR tools
- Evaluated binding energies, interaction profiles, and structure–activity relationships

**Tools used:** PyRx | AutoDock Vina | UCSF Chimera | PyMOL | Swiss-Model

🔗 [View Repository](https://github.com/arundhathiharishchandra-20/rxra-fatty-acid-docking)
