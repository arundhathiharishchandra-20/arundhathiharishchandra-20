## 🔬 Featured Project

### 🧬 Integrated Multi-Omics Analysis of DLBCL
**Dataset:** PRJNA605794 — 129 DLBCL patient samples (RNA-seq + WGBS)

**What I did:**
- Built complete RNA-seq pipeline: FastQC → fastp → HISAT2 → featureCounts → edgeR TMM normalization
- Performed WGCNA co-expression network analysis → 11 modules, identified hub genes (KDM5D/UTY, COL5A2, CD247)
- Built complete WGBS pipeline processing 51 samples with 12 sequencing runs each using Bismark + samtools
- Performed MOFA2 multi-omics integration linking DNA methylation to gene expression patterns
- GO/KEGG pathway enrichment analysis using gprofiler2

**Tools used:** Python | R | Bash | Bismark | methylKit | MOFA2 | WGCNA | edgeR
